# Palmetto Footbrawl

Palmetto Footbrawl is a playable browser game prototype built with plain HTML, CSS and JavaScript for GitHub Pages.

## Direct game URL

https://ccnjh97wh7-arch.github.io/games/palmetto-footbrawl/

## Teams

- Upstate Tigers — orange and purple
- Capital Gamecocks — garnet and black

The prototype uses a stylized retro look and local two-player controls.

## Controls

### Upstate Tigers

- W, A, S, D: move
- F: tackle or punch
- G: pass the ball
- H: short burst or dive

### Capital Gamecocks

- Arrow keys: move
- K: tackle or punch
- L: pass the ball
- ; : short burst or dive

## Notes

- Each team has five players.
- The human controls the teammate closest to the ball.
- Dead archive entries are skipped on the site by the schedule logic, but this game is its own standalone prototype.
- This is an original prototype inspired by the feel of 16-bit arcade sports games, not a copy of an existing title.
